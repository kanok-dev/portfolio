# Portfolio Infographic Context

Use this file as the full context brief for another model to generate a new infographic-style portfolio page or PDF.

## Objective

Generate a premium executive infographic portfolio for a Senior Full-Stack & AI Engineer.

The output should feel:
- high-trust
- executive
- modern
- editorial
- enterprise-ready
- print-friendly

It should not feel like:
- a generic Tailwind landing page
- a startup marketing page
- a noisy motion-heavy concept
- a dark UI that prints poorly

## Preferred Output

Primary target:
- standalone HTML file

Secondary target:
- exportable PDF from that HTML

Suggested format:
- A4 landscape
- one-page executive infographic
- print-first layout

## Design Direction

Recommended style blend:
- Editorial Grid / Magazine
- Executive Dashboard

Visual principles:
- strong hierarchy
- large headline and compact summary
- high contrast text
- restrained premium palette
- navy + blue + warm neutral accents
- compact cards and metric blocks
- clear domain grouping
- minimal decorative clutter

Typography direction:
- bold modern sans for headings
- clean sans for body
- optional mono font for labels/kickers

## Output Constraints

The generated result should:
- preserve accuracy of project domains and counts
- not invent extra projects
- not use emojis as icons in the final design
- remain readable when printed to PDF
- work as a standalone HTML file without a build step
- use print-safe CSS
- avoid low-contrast text over dark backgrounds in print mode

## Print Requirements

- support A4 landscape
- use `@page` and `@media print`
- ensure text remains dark and readable when backgrounds are not printed
- avoid depending on transparency alone for hierarchy
- keep page to one infographic sheet if possible

## Suggested Section Structure

1. Hero / identity block
2. Snapshot metrics
3. Delivery lens / value statement
4. Domain coverage map
5. Capability stack
6. Impact / system patterns
7. Footer with portfolio URL and positioning

## Tone Guide

Use language and structure that signals:
- seniority
- credibility
- enterprise delivery
- product thinking
- technical range

Avoid:
- overclaiming
- vague hype phrases
- flashy consumer-brand aesthetics
- excessive gradients or decorative gimmicks

## If Generating HTML

Preferred technical constraints:
- one standalone `.html`
- inline CSS
- optional Google Fonts
- no framework dependency required
- browser-openable directly

## If Generating PDF Directly

Prefer generating HTML first and exporting from it.

Reason:
- easier iteration
- better print control
- easier maintenance
- repeatable output
